# Amazon S3 Service Guide

## 1. Why We Need It
Scope Creep Ledger stores raw uploaded client conversation files (`.txt`, `.csv`, WhatsApp exports) securely in Amazon S3. This preserves the original raw audit file untouched before parsing and classification.

## 2. What It Does
Amazon S3 (Simple Storage Service) is an object storage service. In our application:
- Stores original uploaded conversation files under object key `projects/{projectId}/conversations/raw_export.txt`.
- Provides an immutable audit record of raw conversation evidence.

## 3. What We Need to Create
A private S3 Bucket named `scope-creep-ledger-conversations-dev`.

## 4. AWS Console Steps
1. Log into your AWS Management Console.
2. Ensure your region is set to `us-east-1` (N. Virginia) or your designated project region.
3. Search for **S3** in the top search bar and open the Amazon S3 console.
4. Click **Create bucket**.
5. **Bucket details**:
   - Bucket name: `scope-creep-ledger-conversations-dev` (Must be unique; add your name suffix if needed, e.g. `scope-creep-ledger-conversations-alex`).
   - AWS Region: `us-east-1`.
6. **Object Ownership**: ACLs disabled (recommended).
7. **Block Public Access settings**: Keep **Block *all* public access** checked (Private bucket).
8. **Bucket Versioning**: Disable (or Enable for backup).
9. **Default Encryption**: Server-side encryption with Amazon S3 managed keys (SSE-S3).
10. Click **Create bucket**.

## 5. Configuration
In your `.env` file (copied from `.env.example`):
```env
AWS_REGION=us-east-1
S3_BUCKET_NAME=scope-creep-ledger-conversations-dev
```

## 6. IAM / Permissions
Your AWS IAM User or Lambda Execution Role requires the following minimal policy:
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject"
      ],
      "Resource": "arn:aws:s3:::scope-creep-ledger-conversations-dev/*"
    }
  ]
}
```

## 7. Environment Variables
- `AWS_REGION`: AWS datacenter region.
- `S3_BUCKET_NAME`: Target S3 bucket name.
- `MOCK_S3`: (Optional) Set to `true` to run offline with local in-memory file storage.

## 8. Local Development
- **Offline / Mock Mode**: Set `MOCK_S3=true` or run without AWS keys. Raw files are saved in local memory.
- **Live AWS Mode**: Uses `@aws-sdk/client-s3` (`PutObjectCommand`, `GetObjectCommand`) server-side inside Lambda or Node.js backend.

## 9. Verification
Run the automated S3 storage test:
```bash
npx tsx services/analyze/src/s3-storage.test.ts
```

## 10. Common Errors
- `NoSuchBucket`: The bucket name in `.env` does not exist in your AWS account or region.
- `AccessDenied`: IAM user/role lacks `s3:PutObject` permissions, or bucket public access blocks are misconfigured for your role.

## 11. Security Notes
- **NEVER** expose AWS keys or pre-signed upload URLs with public permissions to client browsers without backend validation.

## 12. Project Integration
- Used by `services/analyze/src/s3-storage.ts` when a new chat conversation is uploaded via `POST /analyze`.

## 13. Cleanup
To delete the S3 bucket: Open S3 Console -> Empty bucket -> Delete bucket.
