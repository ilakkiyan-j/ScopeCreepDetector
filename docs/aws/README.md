# Documentation — AWS Service Setup Guides

This directory contains beginner-friendly step-by-step guides for setting up and configuring AWS services used in Scope Creep Ledger.

Guide format for each AWS service:
1. Why We Need It
2. What It Does
3. What We Need to Create
4. AWS Console Steps
5. Configuration
6. IAM / Permissions
7. Environment Variables
8. Local Development
9. Verification
10. Common Errors
11. Security Notes
12. Project Integration
13. Cleanup
